# Formularios de Google

Esta carpeta tiene un script de Google Apps Script para crear dos formularios como los ejemplos:

- Confirmacion de asistencia.
- Sugerencia de canciones.

## Como crearlos

1. Ir a https://script.google.com/.
2. Crear un proyecto nuevo.
3. Abrir el archivo `create-wedding-forms.gs` de esta carpeta.
4. Copiar todo su contenido y pegarlo en `Code.gs`.
5. Ejecutar la funcion `createWeddingForms`.
6. Aceptar los permisos que pide Google.
7. Abrir `View > Logs` o `Execution log`.
8. Copiar los links marcados como `Publico`.

## Ajustes recomendados en Google Forms

Despues de crearlos, revisar en cada formulario:

- Que acepte respuestas.
- Que no requiera iniciar sesion.
- Que no limite a una respuesta por persona.
- Tema visual: fondo claro, detalle violeta/lirio si queres que combine con la invitacion.
