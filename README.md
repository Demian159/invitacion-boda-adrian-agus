# Invitación web de boda

Sitio estático mobile-first para la boda de Adrián y Agus. Está pensado para publicarse gratis con GitHub Pages.

## Archivos principales

- `index.html`: contenido de la invitación.
- `styles.css`: diseño visual.
- `script.js`: cuenta regresiva, links pendientes y botones de copiar.
- `assets/lilies-hero.png`: imagen floral usada en la portada.
- `adrian-agus-boda.ics`: archivo de calendario descargable.
- `google-forms/`: script e instrucciones para crear los formularios de Google.

## Links externos

Los formularios de RSVP, sugerencia de canciones y el álbum de Google Photos ya están enlazados en `index.html`.

## Publicación con GitHub Pages

1. Subir estos archivos a un repositorio público en GitHub.
2. Ir a `Settings > Pages`.
3. En `Build and deployment`, elegir `GitHub Actions`.
4. Hacer push a la rama `main`.
5. El workflow `Deploy to GitHub Pages` publica el sitio automáticamente.
